# Local Development

Rules for managing the development environment's dependencies.

- npm packages are managed with pnpm at the version in `packageManager` (`package.json`). Versions are pinned exactly (`save-exact` in `pnpm-workspace.yaml`); `minimum-release-age` keeps packages published less than a day ago out. Change the lockfile only through pnpm and include `pnpm-lock.yaml` in the same commit as `package.json`.
- Node.js is the version in `.node-version`. Other tools (Node, pnpm, gitleaks, elan) come from the nix dev shell (`flake.nix`), entered through direnv (`use flake`) or `nix develop`. Nothing is installed globally.
- The Lean toolchain is managed by elan from `lean-toolchain`; the first `lake build` downloads it. `.lake/` is build output and is gitignored.
- In a git clone or worktree, run `pnpm install` to install dependencies and the pre-commit hook. `allowBuilds` in `pnpm-workspace.yaml` allows only lefthook's dependency build script and denies esbuild's (its binary comes through pnpm's platform-specific optional dependency, not a download script); the repository's `prepare` script runs `lefthook install`. Run `lake build` before `pnpm test` in a fresh checkout.
- For a source copy without `.git`, use `pnpm install --ignore-scripts`: hook installation requires a git repository. If you use this command in a git checkout, run `pnpm exec lefthook install` afterward to enable hooks.
- CI deliberately skips scripts because it does not need git hooks: `.github/actions/setup-node` installs pnpm at the `packageManager` version and runs `pnpm install --frozen-lockfile --ignore-scripts`; `leanprover/lean-action` installs elan and runs `lake build`.
- Loading-session tests need the pinned Playwright Chromium: reuse an existing installation, or run `pnpm exec playwright install chromium` when absent (`--with-deps chromium` in Linux CI). `pnpm test --project loading` launches it with the sandbox enabled and without software-WebGL opt-in. No browser download or retry occurs in the library. Ubuntu CI permits user namespaces only for Playwright's cached Chromium executables through an AppArmor profile; it does not disable Chromium's sandbox or the system-wide namespace restriction. The loading-only implementation does not use FFmpeg; encoding will document its installation when that context ships. See `docs/guidelines/quality-assurance/exploratory-testing.md`.
- Before adding a production dependency, check its license against `scripts/check-licenses.ts` and whether it belongs behind an optional subpath (`REVIEW.md`, Dependencies).
