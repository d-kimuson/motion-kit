# core

The master clock. core defines the Composition, the timeline it runs on, how Sequences and Transitions place scenes in time, and the Time Module that converts between frames and time. It is not responsible for how anything looks.

## Ubiquitous Language

| Term              | Code                             | Definition                                                                                                                                                               |
| ----------------- | -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Composition       | `Composition`                    | The root of a video: fps, duration, resolution, and a tree of scenes placed in time.                                                                                     |
| Global Frame      | `globalFrame`                    | The integer index of an output frame, counted from 0 over the whole Composition.                                                                                         |
| Timeline Time     | `TimelineTime`                   | A time on the Composition timeline, kept as an exact rational value until the Time Module converts it.                                                                   |
| Local Time        | `time` (from `useTime`)          | Time relative to the start of the enclosing Sequence, in seconds.                                                                                                        |
| Presentation Time | `presentationTime`               | The timeline time at which an output frame is sampled.                                                                                                                   |
| Frame generation  | Not implemented yet              | The monotonically increasing per-realm request identity shared by React, asset and integration acknowledgements, distinct even for repeated requests for the same frame. |
| Time Module       | `src/core/timeline`              | The only place that converts seconds, timeline time, and frames, and defines rounding and comparison. Specified in Lean.                                                 |
| Sequence          | `Sequence`                       | A scene's display period on the timeline, the half-open interval `[start, end)`.                                                                                         |
| Transition        | `Transition`                     | A period in which two adjacent scenes of a `TransitionSeries` are mounted at once and share a progress value.                                                            |
| Seekability Tier  | `seekability: 'A' \| 'B' \| 'C'` | How far a component's output at a time is independent of the frames rendered before: A guaranteed, B controlled by an integration, C uncontrolled.                       |
| Asset Readiness   | `useAsset`                       | Whether every asset a frame needs (font, image, video frame, model, texture) is loaded, reported before capture; a failure is a diagnostic, not a silent skip.           |

## Invariants

- Within the supported A/B paths and a fixed environment, a frame is a pure function of its Presentation Time: rendering frame N gives the same output whatever frame was rendered before. Tier C remains usable, not covered by this guarantee; in Phase 1 the Browser Renderer emits `seek.uncontrolled` when an integration is identified as Tier C.
- A Sequence contains time `t` exactly when `start <= t < end`; adjacent Sequences share no frame.
- Frame boundaries are not rounded to integers before the Time Module converts them; fps may be rational (30000/1001).
- The total duration of a `TransitionSeries` is the sum of its scenes minus the sum of its overlaps.
- A component that cannot be identified is never assumed to be Tier A or B.
- core's contract provides one explicit-time runtime for the Browser Renderer and the future preview to consume; it does not assert that a preview exists. Presentation Time stays fixed while registered work settles. Completion belongs to the active frame generation and resource versions, not just a frame number; allocating a queued generation does not invalidate the active one. Resource-version changes re-settle within that generation; cancellation or supersession aborts it without publication. The [readiness barrier contract](../../decisions/20261024-time-control-and-frame-capture.accepted.md#readiness-barrier-contract) defines exclusive ownership, queueing and deadlines.

## Seekability

The [accepted Phase 0 ADR](../../decisions/20261024-time-control-and-frame-capture.accepted.md) defines the clock and readiness contract. These classifications are scoped to [Spike A](../motion/knowledge/spike-a-seekability.md) and [Spike B](../three/knowledge/spike-b-seekability.md), not guarantees for whole libraries. A is stateless value evaluation; B needs the verified adapter and acknowledgement; C has uncontrolled time/history. Unverified means no A/B claim, not a fourth Tier; unknown integrations receive C treatment until qualified.

| Feature / examined use                                                 | Tier                             | Reason and boundary                                                                                                                                                            |
| ---------------------------------------------------------------------- | -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| External MotionValue bound to motion.div x                             | B                                | Absolute value writes, no velocity/history dependence or live animation; await per-frame postRender.                                                                           |
| Numeric motion.div style.x props                                       | B                                | React flushSync leaves queued Motion work; postRender is required.                                                                                                             |
| Paused animate(MotionValue, [0,160]) controls                          | B                                | Explicit keyframes, autoplay disabled, pause and absolute time assignment; play/speed/repeat/timelines/callbacks/implicit starts are unverified.                               |
| Paused animate(element, opacity) controls                              | B                                | Native animation was verified paused at the supplied time; not all WAAPI properties/compositor paths.                                                                          |
| Paused animate() spring with fixed initial conditions                  | B                                | Explicit parameters/keyframes/initial velocity and absolute seek; not live spring state.                                                                                       |
| Fresh spring(options).next(timeMs)                                     | A value / B Motion DOM binding   | Fresh evaluator and fixed inputs remove history; retained mutable generators and the full Spring/Retarget API are unverified.                                                  |
| Live useSpring(source)                                                 | C                                | Position/velocity depend on prior animation state; equal targets do not determine equal positions.                                                                             |
| AnimatePresence exit                                                   | C                                | Exit-node retention depends on mounting/traversal history; no absolute-time exit lifecycle in the tested form.                                                                 |
| layout animation                                                       | C                                | Projection requires a previous layout measurement absent on fresh mount; structurally history-dependent.                                                                       |
| Autonomous motion.div animate                                          | C                                | Browser elapsed time, not supplied Presentation Time, progresses the animation.                                                                                                |
| Pure R3F scalar/transform formulas                                     | A values / B rendered expression | Formula uses only supplied time; WebGL still needs integration settlement.                                                                                                     |
| Canvas frameloop="never" + root-local advance(seconds, false)          | B                                | Stopped clock/no independent loop; root-local update excludes global effects. Manual Advance alone does not qualify callbacks.                                                 |
| Camera position + lookAt(0,0,0)                                        | B                                | Absolute orbit/push overwrites pose; damping, automatic fitting, XR and previous-pose interpolation are excluded.                                                              |
| Group rotation/translation                                             | B                                | Overwrite every animated component; deterministic index-derived object positions.                                                                                              |
| Shader uTime assigned from absolute time                               | B                                | Tested procedural shader has no feedback/stochastic history or wall-clock uniform.                                                                                             |
| GPU capture with preserved framebuffer, fixed DPR/size, pinned browser | B                                | Submitted-work settlement and screenshot/readback agreement established in one environment, not cross-backend equality.                                                        |
| Delta-integrating useFrame rotation / accumulated uniform              | C                                | History controls differ; signed deltas, abs(delta) or clamping cannot reconstruct an absolute state.                                                                           |
| Camera updated only at new maximum time / dropping reverse advance     | C                                | Prior maximum or discarded reverse requests leave stale pose/time.                                                                                                             |
| Physics, damping controls, autonomous timers/rAF, temporal feedback    | C / unverified                   | Not implemented by B; hidden state/independent progression cannot be inferred seekable from manual stepping.                                                                   |
| Async models/textures, Suspense, shader/asset readiness                | Unverified by B                  | B has local geometry/synchronous shaders. D verifies finite GLTF/texture cases; the registry plus commit/GPU contract is required, not automatic Tier B for arbitrary loaders. |

No tested Motion DOM path is A. Standard Animate/Reveal/Stagger are not blanket-certified before implementation; a Motion DOM-backed implementation is B. The four Motion negative controls and four R3F history controls are counterexamples, not merely features awaiting wrappers. Public integration APIs, broader behavior coverage and explicit-time replacements remain later-phase work in the ADR's risk handoff.
