# preview

A human's fast authoring loop. preview is the browser page `motion-kit preview` serves: it plays, scrubs and steps a Composition in the user's own browser with its declared audio, and shows the timeline of named Sequences, audio clips and the assets the frames used. It is not the render: it never encodes, never captures a screenshot, and may differ from the MP4 (WebGL implementation, encoding loss, the audio mix). It runs in the browser outside the Composition's iframe and reaches the Composition only through the preview protocol; Node-side serving belongs to render's loading service and the command to agent (its [Preview command](../agent/CONTEXT.md)).

## Ubiquitous Language

| Term               | Code                                                                     | Definition                                                                                                                                                                                                                                                                                                                                                                             |
| ------------------ | ------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Preview host page  | `startPreviewHost`                                                       | The page the loading service serves at `__motion-kit/preview/`: the controls, timeline and audio, with the Composition realm embedded in an iframe. Built as a separate entry.                                                                                                                                                                                                         |
| Realm connection   | `Realm`                                                                  | The host's connection to one Composition realm (core's term; here the iframe running the user's entry): `list`, `mount`, `show`, `inspect` and `describe` requests over a `MessagePort`. A reload replaces it.                                                                                                                                                                         |
| Preview host mode  | `?host=preview`, `servePreviewPort`                                      | The mode of the composition shell that the page URL fixes: the realm serves the preview protocol and installs no `window.__motionKit`, no Playwright callbacks.                                                                                                                                                                                                                        |
| Preview protocol   | `previewProtocolVersion`, `PreviewRequest`                               | The versioned, Zod-validated messages between host page and realm: a `ready`/`connect` handshake, then `list`, `mount`, `show`, `inspect` and `describe` correlated by `id`.                                                                                                                                                                                                           |
| Show               | `show`, `ShowOutcome`                                                    | Display one frame in the realm: it settles the frame as source `preview`, completes the lease without a screenshot, and replies `shown` (with the Sequence Spans and Registered assets), `failed` (with the Registered assets its diagnostics name) or `aborted`.                                                                                                                      |
| Inspect            | `inspect`, `inspectPoint`, `InspectedElement`                            | Ask the realm which element of the mounted Composition is at a design-pixel point: its selector, text, `data-source` and box. It reads the committed DOM, skips elements that cannot be seen and prefers the topmost one that draws something to a layout box spanning it.                                                                                                             |
| Describe           | `describe`, `describeTree`, `ElementTree`                                | Ask the realm for every element of the mounted Composition as a tree, each described as Inspect describes one, with whether it can be seen; at most 2000 elements, marked truncated past that.                                                                                                                                                                                         |
| Registered asset   | `RegisteredAsset`, `SeenAsset`                                           | A font or image a shown frame registered with `useAsset` (core), with its redacted source and status (`pending`, `ready`, `failed`). The host keeps those seen since the last reload with the frame each was first seen at.                                                                                                                                                            |
| Presenter          | `Presenter`                                                              | The rule that at most one `show` is in flight and the latest wanted frame follows its reply, so a slow frame is shown late rather than starved.                                                                                                                                                                                                                                        |
| Playhead           | `PreviewState.playhead`                                                  | The frame the user is on. While playing it is derived from the audio clock; the Composition realm may still be showing an earlier frame.                                                                                                                                                                                                                                               |
| Playback           | `Playback`                                                               | `paused` at a frame, or `playing` from an anchor frame and anchor time on the audio clock.                                                                                                                                                                                                                                                                                             |
| Audio clock        | `AudioContext.currentTime`                                               | The clock that drives the Playhead while playing, because drift between picture and sound is what the ear notices.                                                                                                                                                                                                                                                                     |
| Preview fps        | `PreviewQuery.fps`, `--preview-fps`                                      | How many frames per second playback samples (1-60, default `defaultPreviewFps` = 12). It is a sampling rate for the picture, not the Composition's fps.                                                                                                                                                                                                                                |
| Preview query      | `PreviewQuery`, `previewQueryString`                                     | The selection (Composition id, props, Preview fps) carried in the host page URL, so the server keeps no selection state.                                                                                                                                                                                                                                                               |
| Audio schedule     | `audioSchedule`, `ScheduledClip`                                         | The declared clips still audible from a frame, as `{ src, delay, offset, duration, gain }` in seconds computed through the Time Module and capped at the Composition duration.                                                                                                                                                                                                         |
| Audio player       | `createAudioPlayer`                                                      | Decodes each distinct `src` once and plays an Audio schedule through Web Audio gain nodes.                                                                                                                                                                                                                                                                                             |
| Muted source       | `mutedSources`                                                           | A `src` the user silenced; kept in `localStorage` per project root (so per origin, port included) and applied to every clip of that source.                                                                                                                                                                                                                                            |
| Reload             | `reload` (server-sent event)                                             | The signal that a served module changed; the host page loads a new Composition realm and shows the Playhead again. There is no hot module replacement.                                                                                                                                                                                                                                 |
| Preview controller | `createPreviewController`                                                | The host's state machine (`Session`, `Playback`, spans, Registered assets, muted sources) and the Realm connection, audio and timer it drives; the view only renders it.                                                                                                                                                                                                               |
| Preview timeline   | `Timeline` (`timeline.tsx`), `packLanes`                                 | Rows under the transport: the Review comments as markers, the named Sequence Spans the Composition realm has reported, the declared audio clips and the Asset spans, the last three packed into lanes so non-overlapping ones share a row.                                                                                                                                             |
| Asset span         | `AssetSpan`, `assetGroup`, `observeAssets` (`asset-usage.ts`)            | The frames `[start, end)` that used an asset group, as far as the frames shown so far tell. An asset group is one font or image file, or every data URL of a kind; a numbered name stays its own group (`IMG20261031111549.jpg` and `IMG20261031111550.jpg` are two photos). A span covers the frames playback skipped between two frames it showed in a row that both used the group. |
| Side panel         | `SidePanel` (`side-panel.tsx`)                                           | The tabs next to the stage: Info (the Composition's facts), the named Sequences seen so far (choosing one seeks to its start), Assets (the audio sources with their mute toggles and the Registered assets), Elements (the Describe tree of the paused frame, which outlines an element on the stage and comments on it) and the Review comments.                                      |
| Review comment     | `ReviewComment`, `reviewMarkdown`                                        | A note on a frame or range of frames, about the whole frame, a point or an element, with the named Sequences showing at its first frame and the props the page mounted the Composition with. Copied as Markdown with a command that renders its frame (both ends of a range).                                                                                                          |
| Comment mode       | `createReviewController`, `CommentLayer`                                 | Paused playback with a layer over the stage that highlights the element under the pointer (via `inspect`) and drafts a Review comment on the one clicked. The Elements tab drafts one on an element without a click.                                                                                                                                                                   |
| Page language      | `Locale`, `createLocaleSetting`, `Messages` (`locale.ts`, `messages.ts`) | The language of the page's own text, English or Japanese: the one last chosen with the switch in the transport, kept in `localStorage` for every project (so per origin), else the first of the browser's preferred languages the page has, else English. The review Markdown and the Diagnostics stay English, since a coding agent reads them.                                       |
| Comment book       | `createCommentBook`                                                      | The Review comments of one project root and entry, kept in `localStorage`; the server never stores them.                                                                                                                                                                                                                                                                               |

## Invariants

- Preview imports `core` and `src/lib` only (plus React, Zod and the UI libraries `dist/preview.js` bundles: Base UI, class-variance-authority, clsx, tailwind-merge, lucide-react and react-resizable-panels); it never imports `render`, `agent`, `cli`, `three`, `motion`, `theme`, `presets`, Vite, Playwright or Node APIs (lint, `PREVIEW_RESTRICTION`).
- The Composition realm is reached only through the preview protocol over a transferred `MessagePort`. The realm accepts one port, only from its parent window at its own origin; the host accepts the realm only from its own frame at its own origin.
- At most one `show` is in flight, and the Playhead is never reset by a reload: after a reload the new Composition realm shows the Playhead's frame again.
- While playing, the Playhead is `anchorFrame` plus the elapsed audio-clock time floored through the Time Module, clamped to the last frame; paused, it is the exact frame. The last frame ends playback.
- Time arithmetic (frame to seconds, timecode centiseconds, clip delay and offset) goes through the Time Module, never floating-point frame math.
- The server keeps no selection state: the same URL always selects the same Composition, props and Preview fps.
- Preview and renderer share core's Composition runtime and registry loading contract, never a loading session or a Composition realm; a preview realm rejects renderer requests and leases, and the renderer's page rejects preview ones.
