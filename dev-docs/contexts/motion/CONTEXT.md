# motion

Deterministic values from time. motion provides the pure functions (interpolate, spring, keyframes, easing) and the components (Animate, Reveal, Stagger) that turn Local Time into style values. The motion library owns the rich expression; motion-kit owns time and values and never wraps the library thinly.

## Ubiquitous Language

| Term         | Code                                                                    | Definition                                                                                                                                                                                                                                                                    |
| ------------ | ----------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Pure Motion  | `interpolate`, `spring`, `keyframes`, `easing`                          | Stateless evaluation from explicit inputs; `interpolate` and `keyframes` return `Result<number>`, Bézier construction returns `Result<Easing>`, and easing callbacks map progress to a number; see the [Pure Motion contract](adr/20261024-pure-motion-contract.accepted.md). |
| Spring       | `spring(time, { from, to, start, velocity, stiffness, damping, mass })` | A damped spring evaluated in closed form at a time.                                                                                                                                                                                                                           |
| Spring State | `springState`, `SpringState`                                            | Position and analytic velocity of a Spring at an explicit time.                                                                                                                                                                                                               |
| Settle Time  | `springSettleTime`                                                      | Duration from Spring start to the sustained last entry into an absolute position tolerance band.                                                                                                                                                                              |
| Retarget     | `retarget`                                                              | Replacing a Spring by a new Spring that starts at the switch time with the old one's position and velocity; never a mutation of the old one.                                                                                                                                  |
| Animate      | `Animate`                                                               | A component that applies `from`/`to` values to a dedicated wrapper element over `delay`/`duration` with an `easing`.                                                                                                                                                          |
| Reveal       | `Reveal`                                                                | An Animate whose values are a reveal (mask, clip, slide) of its content.                                                                                                                                                                                                      |
| Stagger      | `Stagger`                                                               | A component that gives each child an explicit delay rule and animation.                                                                                                                                                                                                       |
| Wrapper      | `as` prop                                                               | The element Animate renders and animates; children are never style-injected.                                                                                                                                                                                                  |

## Invariants

- Every Pure Motion function returns the same result for the same inputs. `interpolate` and `keyframes` return the shared `Result`, carrying a value or a `Diagnostic`. Every exact stop (first, interior and final) returns that stop's value without invoking easing, even for a non-endpoint-preserving custom easing. Easing shapes segment interiors; immediately after an interior stop, the segment starting there is used. Outside the range, clamped progress still passes through easing, without clamping its output. See the [Pure Motion contract](adr/20261024-pure-motion-contract.accepted.md).
- A Spring is determined by start time, initial value, target, initial velocity, and physical parameters; nothing else. Spring functions return the shared `Result`; Retarget inherits both position and velocity without mutating its input. Settle Time means sustained last entry, not first crossing, and is non-increasing as tolerance grows. See the [closed-form Spring decision](adr/20261024-closed-form-spring.accepted.md) for numerical stability, pre-start behavior and the settle search.
- Spring sampling has the joint numeric domain and mixed error bound below; a finite input alone is not a promise of numerical accuracy for every combination of fields.
- Stateless Pure Motion value evaluation is Tier A; Motion DOM bindings are Tier B only within a verified explicit-time integration with render acknowledgement. Animate/Reveal/Stagger are not blanket-certified A before implementation; see the [core feature table](../core/CONTEXT.md#seekability) and [Phase 0 decision](../../decisions/20261024-time-control-and-frame-capture.accepted.md).

## Spring numeric domain

This is a **joint** domain for `spring` and `springState`, not a Cartesian product of independently safe field ranges. Retarget sampling inherits it; the sustained-settle search additionally requires representable search times and a safely distinguishable last-peak index.

- **Magnitudes:** `|from|`, `|to|`, `|start|`, `|velocity|`, and `|time|` are at most `1e308`, including zero and subnormals. Positive `stiffness`, `damping`, and `mass` range from `2**-1022` (the smallest normal binary64 value) through `1e308`. These ranges leave output headroom below `Number.MAX_VALUE` and cover animation scales by many orders of magnitude, including opposite `1e308` endpoints. Common scaling of the three physical parameters does not change the ODE; their ratios matter as well as their magnitudes.
- **Model and elapsed time:** `t = max(0, time-start)` is representable, the derived rates `a = damping/(2*mass)`, `omega = sqrt(stiffness/mass)`, and the positive slow decay rate are normal and finite, and `omega*t <= 2**20`. Evaluate the ratios using the factored operations in the Spring decision, not an overflowing `stiffness/mass`. The dimensionless time limit is a phase-accuracy limit: about 167,000 natural periods, vastly beyond a visible damped spring transition. Rate rounding creates phase uncertainty proportional to `omega*t`; there is no phase-independent relative-error promise at arbitrarily large times.
- **Root conditioning:** repeated and arbitrarily close roots are included, not excluded by a damping-ratio gap. With `q = sqrt(|a*a-omega*omega|)` evaluated in factored form, `|q*t| < 0.001` uses the signed sixth-order series; at and above that boundary use trigonometric or decaying-real-root expressions. The first omitted cosine/cosh term is at most approximately `2.5e-29` at the boundary. Real-root differences use `expm1`; cancellation of opposing contributions precedes restoration of the half-scale for overflowing endpoint differences.
- **Modal and output representability:** the decayed displacement/velocity contributions and their partial sums must fit binary64 in the working scale (half-scale when `from-to` overflows), and the requested exact outputs have magnitude at most `1e308`. This is a physical-amplitude constraint as well as a rate constraint: individually unrepresentable opposing modes are not promised merely because their exact sum is small. Bare exponentials may underflow; exponent-separated products retain representable contributions. In the reported `from=1e308,to=-1e308,k=c=1e308,m=1,t=1e-310` case, the half-scaled terms and their sums fit, so it is inside the domain.

Inside this joint domain the requested outputs are finite, with the mixed bound

`|computed - exact| <= R*|exact| + A*S`, where `R = 1e-8` and `A = 1e-8`.

For position, `S = max(|from|, |to|, |velocity|/omega, 2**-1022)`; for velocity use `max(omega*S, 2**-1022)`. Scales in this statement are mathematical quantities, not instructions to materialize an overflowing product in JavaScript. The normal-number floor accommodates subnormal rounding. Relative error is unbounded near zero crossings; the absolute term is essential. It also covers phase uncertainty up to the dimensionless-time boundary. This is a binary64 numerical contract verified by analytic fixtures and properties, not a certified interval or floating-point Lean proof. Same-runtime determinism does not imply cross-engine last-bit identity.

**Outside the joint domain, evaluation is best-effort; no accuracy or finiteness guarantee is advertised.** The boundaries are not input clamps and introduce no unsupported-combination Diagnostic. `motion.non-finite-result` means either the requested output or a required model/solver computation could not be represented; it does not assert that the mathematical output overflows. For example, `stiffness=1e308,mass=1e-310,damping=1,from=1,to=0,velocity=0,time=start=0` has exact initial state `{position:1,velocity:0}`, but its model frequency is approximately `1e309`, so sampling returns that Diagnostic. An unsafe settle peak index likewise means the peak search could not be carried out safely, not that the motion diverges. Non-finite fields or nonpositive physical parameters remain `motion.invalid-input`.

`src/motion/spring.test.ts` walks just below, at, and just above the magnitude, physical-scale, dimensionless-time and signed-series boundaries, exercises coalescing roots, and distinguishes representable states from unrepresentable model/output computations. It also checks both signs of the overflowing-endpoint regression, with zero and dominant initial velocities. See [verification evidence](knowledge/spring-verification.md).
