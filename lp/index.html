motion-kit is an agent-first framework for programmatic video. Your coding agent writes the scenes in React/TSX, looks at its own frames, and renders the MP4. Every video on this page was made with it.

How it works

Built for the agent's loop: write, look, fix, render

Every frame is a pure function of time, every command answers in JSON, and every failure is a Diagnostic with a stable code and a hint, so the agent can check its own work.

The agent writes React

A video is a Composition: a React component plus its size, frame rate and duration, on a deterministic timeline.

It checks its own frames

contact-sheet samples the timeline into one labelled PNG, so the agent sees the whole flow in a single image.

You review in the preview

preview plays it in the browser. Comment on an element and hand the comments back as Markdown.

It renders the MP4

render captures the frames in Chromium and encodes them with FFmpeg, the same pixels every time.

Get started

Add the skill, then ask for a video

The motion-kit skill tells your coding agent how to set up a project, run the CLI and read the guides that ship with the package. 

# any agent that reads skills
npx skills add d-kimuson/motion-kit

# or as a Claude Code plugin
/plugin marketplace add d-kimuson/motion-kit
/plugin install motion-kit@motion-kit
# or try it without the skill: point the agent at it in your prompt
